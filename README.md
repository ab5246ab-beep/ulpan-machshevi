# אולפן מחשבי אישי

הפרדת שיר לקול הזמר ולפלייבאק, אצלך בדפדפן. השיר לא עולה לשרת.

אם התוכנה שימושית לך, שים כוכב לריפו. זה עוזר לאחרים למצוא אותה.

## מה היא עושה

- בוחרים שיר בפורמט MP3, WAV, FLAC, M4A או OGG.
- המודל מפריד אותו לשני קבצים: קולות הזמר, ופלייבאק בלי הקול.
- שני הקבצים נשמרים אוטומטית בספריות בדפדפן.
- אפשר לחפש, לפתוח תיקיות, לגרור שיר לתיקייה, לשנות שם, לייצא ולייצא כמה קבצים יחד.
- הייצוא הוא MP3 או WAV, והבחירה האחרונה נשמרת.
- אפשר לבחור את כרטיס המסך שהדפדפן רואה, ולמחוק את המודל מהדפדפן.

ההפרדה רצה על כרטיס המסך דרך WebGPU, ב־Chrome או Edge. בפעם הראשונה המודל יורד ונשמר בדפדפן. אחר כך אין צורך בהורדה מחדש. שיר ארוך מ־10 דקות לא מתחיל בהפרדה.

## איך משתמשים
נכנסים לקישור ומתחילים להנות https://bird-cherry-lark-garden.grok.me
## איך מריצים

```bash
npm install
npm run dev
```

התוכנה נפתחת על `http://127.0.0.1:8080`.

## המודל

ההפרדה משתמשת ב־**Kim Vocal 2** של Kimberley Jensen. המשקלים ברישיון MIT, והפלייבאק מחושב כהפרש בין השיר המקורי לקול שהמודל הוציא. הקובץ עצמו לא כלול בריפו. הדפדפן מוריד אותו בהפעלה הראשונה.

המודל הקודם, שלא היה לו רישיון ברור, אינו בשימוש.

## רישיונות של רכיבים

| רכיב | רישיון |
|---|---|
| Kim Vocal 2, Kimberley Jensen | MIT |
| ONNX Runtime Web | MIT |

רישיון MIT מחייב לשמור את שם היוצר ואת טקסט הרישיון. רישיון LGPL מתיר שימוש מסחרי, ודורש לצרף את הרישיון ולאפשר החלפת ספריית הקידוד.

הפרדת שיר של אמן אחר אינה מעניקה זכות למכור את קובץ הקול או את הפלייבאק. הזכויות על ההקלטה נשארות אצל בעלי השיר.
